# Task Observer

This skill provides a meta-cognitive layer to development, ensuring tasks are completed thoroughly and accurately.

## The Observer Loop

1.  **Analyze**: Break down the user's prompt into atomic requirements.
2.  **Plan**: Formulate a step-by-step execution plan before writing any code.
3.  **Execute**: Implement the plan methodically.
4.  **Verify**: Cross-reference the implemented code against the atomic requirements from step 1. Did we miss anything?
5.  **Reflect**: Is the solution elegant? Does it introduce technical debt?

## Checklist

-   [ ] All explicit requirements met?
-   [ ] All implicit requirements (e.g., error handling, responsive design) met?
-   [ ] Code passes linting and type checking?
