# Modern Frontend Design

This skill ensures the frontend is built using the latest industry standards for aesthetics, performance, and maintainability.

## Core Principles

1.  **Component Driven**: Build isolated, reusable, and testable components.
2.  **Responsive by Default**: Mobile-first approach. Ensure layouts adapt seamlessly to all screen sizes.
3.  **State Management**: Use appropriate state management (local state for UI, context/Zustand for global state, React Query/SWR for server state).
4.  **Accessibility (a11y)**: Semantic HTML, ARIA attributes where necessary, keyboard navigation, and screen reader compatibility.

## Tech Stack Preferences (Unless specified otherwise)

-   Tailwind CSS for utility-first styling.
-   Radix UI or similar headless accessible primitives.
-   Lucide or Radix Icons for iconography.
