# Taste and Aesthetics

Good taste is the difference between a functional product and a loved product. This skill brings aesthetic intuition into the development process.

## Design Tenets

1.  **Visual Hierarchy**: Guide the user's eye naturally. Use size, weight, and color contrast to establish a clear order of importance.
2.  **Breathing Room**: Master whitespace. Elements need room to breathe. Avoid cluttered, dense interfaces.
3.  **Typographic Excellence**: Choose fonts carefully. Establish a consistent type scale. Pay attention to line-height, letter-spacing, and readability.
4.  **Harmonious Color**: Use curated color palettes. Ensure proper contrast ratios for accessibility while maintaining visual elegance.

## Implementation Focus

-   Implement subtle hover and focus states for all interactive elements.
-   Ensure alignment is mathematically perfect (using CSS Grid/Flexbox).
-   Use soft, realistic shadows rather than harsh drop shadows.
