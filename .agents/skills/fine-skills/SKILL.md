# Fine Skills

This skill activates a heightened sense of precision and detail-oriented engineering.

## Core Principles

1.  **Precision Engineering**: Every line of code must have a clear, undeniable purpose. Avoid "catch-all" solutions.
2.  **Edge Case Mastery**: Anticipate and handle edge cases proactively. Consider null values, empty arrays, network failures, and race conditions.
3.  **Micro-Optimizations**: Where performance is critical, apply fine-grained optimizations (e.g., avoiding unnecessary allocations, using efficient data structures).
4.  **Immaculate Formatting**: Maintain perfect consistency in spacing, naming conventions, and code structure.

## Execution Checklist

-   [ ] Are there any hidden side effects?
-   [ ] Have all potential error states been accounted for?
-   [ ] Is the type system being used to its maximum potential to prevent runtime errors?
-   [ ] Can this logic be simplified without losing precision?
